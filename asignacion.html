Modelo de asignación

Distribuye tareas entre recursos para minimizar el costo o el tiempo con el método húngaro.

Modelo de asignación

Relaciona recursos con actividades mediante una matriz de costos, tiempos, distancias o beneficios. Cada recurso se asigna a una sola actividad y cada actividad recibe un solo recurso.

Es un caso particular del modelo de transporte, con una relación uno a uno. Las variables suelen ser binarias:

xᵢⱼ = 1 si el recurso i se asigna a la actividad j
xᵢⱼ = 0 si no se realiza esa asignación

Puede resolver minimización o maximización. Para aplicar directamente el Método Húngaro se necesita una matriz cuadrada; cuando las cantidades difieren se agregan filas o columnas ficticias.

Método Húngaro

Transforma la matriz para generar ceros y encontrar una combinación óptima. Los ceros de la matriz transformada no representan costos reales iguales a cero.

Reducción por filas

Restar el mínimo de cada fila a todos sus elementos.

Reducción por columnas

Restar el mínimo de cada columna a todos sus elementos.

Ceros independientes

Seleccionar ceros sin repetir fila ni columna, hasta completar una asignación por recurso y actividad.

Ajuste de la matriz

Si faltan ceros independientes, cubrir los ceros con el menor número de líneas horizontales y verticales. Restar el menor valor no cubierto a los elementos no cubiertos y sumarlo en las intersecciones de líneas. Repetir hasta completar la asignación.

Minimización y maximización

Para costos, tiempos o distancias se busca el menor total. Para beneficios, se transforma primero a minimización. El resultado final siempre se calcula con los valores originales.

Matrices no balanceadas

Una fila o columna ficticia puede representar un recurso sin utilizar o una actividad sin asignación real.

Aplicaciones, ventajas y limitaciones

Se aplica a trabajadores y puestos, técnicos y órdenes, máquinas y procesos, vehículos y rutas, vendedores y zonas, ingenieros y proyectos o recursos computacionales y trabajos.

Es sistemático, encuentra una asignación óptima y evita probar innecesariamente todas las combinaciones. Puede implementarse con herramientas informáticas.

Su condición esencial es la relación uno a uno. Si un recurso atiende varias actividades o una actividad necesita varios recursos simultáneamente, puede requerirse otro modelo. Los datos deben representar adecuadamente la situación real.

Conclusión

Las reducciones facilitan la selección de asignaciones, pero el total se calcula con la matriz original. En este ejemplo, las cuatro tareas se asignan con un tiempo mínimo de 38 horas.
