Formulación de modelos

De una situación real a sus variables, objetivos y restricciones.

Fase 1 Agosto de 2026

Fundamentos

¿Qué significa formular un modelo?

Transformar una situación real en un modelo matemático permite identificar las decisiones, organizar los datos y expresar los objetivos y las limitaciones del problema.

La formulación de modelos consiste en identificar los elementos importantes de un problema real y representarlos mediante expresiones matemáticas.

No se pretende reproducir todos los detalles de la realidad. Se seleccionan aquellos que tienen relación directa con la decisión que se desea tomar.

Por ejemplo, si una empresa necesita determinar cuánto producir de dos productos, debemos identificar qué cantidades se pueden decidir, qué recursos están disponibles, qué objetivo se quiere alcanzar y qué condiciones deben respetarse.

Modelo matemático

Un modelo matemático representa un sistema o problema mediante variables, parámetros, ecuaciones, desigualdades y otras condiciones.

3x₁ + 2x₂ ≤ 100

Esta expresión podría representar la disponibilidad de un recurso. No constituye por sí sola todo el modelo: es una restricción que debe acompañarse de las variables, la función objetivo y las demás condiciones.

Estructura del modelo

Elementos de un modelo

Variables de decisión

Son las cantidades que necesitamos determinar. Representan aquello sobre lo que tenemos capacidad de decidir.

En una empresa que fabrica dos productos, x₁ representa las unidades del producto A y x₂ las unidades del producto B.

Parámetros

Son los datos conocidos: ganancias, costos, horas disponibles, materia prima, capacidad de producción y demanda.

Si una unidad del producto A genera Q40 de ganancia, ese valor es un parámetro.

Función objetivo

Expresa matemáticamente lo que queremos conseguir: maximizar ganancias o producción, o minimizar costos, tiempo o desperdicios.

Restricciones

Representan las limitaciones y condiciones que deben cumplirse, como la disponibilidad de materiales, horas o presupuesto.

No negatividad

Cuando las variables representan cantidades que no pueden ser negativas, se establece x₁ ≥ 0 y x₂ ≥ 0. Una cantidad negativa de productos fabricados no tendría sentido en este contexto.

Variable de decisión: lo que necesitamos determinar.

Parámetro: lo que ya conocemos.

Construir la función objetivo

Si cada unidad del producto A genera Q40 y cada unidad del producto B genera Q30, la ganancia total es Z = 40x₁ + 30x₂. Si buscamos la mayor ganancia posible, escribimos:

Maximizar Z = 40x₁ + 30x₂

Interpretar las restricciones

En 3x₁ + 2x₂ ≤ 100, cada unidad de x₁ utiliza tres unidades de un recurso, cada unidad de x₂ utiliza dos y existen como máximo 100 unidades disponibles.

El signo depende de la condición que presenta el problema:

CondiciónExpresión de ejemploInterpretación
Como máximox₁ + x₂ ≤ 100No superar 100 unidades
Como mínimox₁ + x₂ ≥ 100Alcanzar al menos 100 unidades
Exactamentex₁ + x₂ = 100Cumplir una cantidad de 100 unidades

Aplicación paso a paso

Ejemplo práctico: producción de camisetas

Una pequeña empresa fabrica camisetas básicas y premium. Desea formular un modelo para maximizar su ganancia.

Dato por camisetaBásicaPremiumDisponible
Horas de trabajo2360
Unidades de tela3260
GananciaQ20Q30—

Paso 1. Definir las variables

x: cantidad de camisetas básicas que se fabricarán.

y: cantidad de camisetas premium que se fabricarán.

Paso 2. Formular el objetivo

Cada camiseta básica genera Q20 y cada premium genera Q30.

Maximizar Z = 20x + 30y

Paso 3. Expresar el límite de trabajo

Cada camiseta básica requiere dos horas y cada premium requiere tres. La empresa dispone de 60 horas:

2x + 3y ≤ 60

Utilizamos ≤ porque no podemos superar las horas disponibles.

Paso 4. Expresar el límite de tela

Cada camiseta básica utiliza tres unidades de tela y cada premium utiliza dos. Existen 60 unidades:

3x + 2y ≤ 60

Paso 5. Establecer la no negatividad

x ≥ 0, y ≥ 0

Modelo completo

Maximizar Z = 20x + 30y
Sujeto a:
2x + 3y ≤ 60
3x + 2y ≤ 60
x, y ≥ 0

El modelo ya está formulado. Determinar sus valores de solución corresponde a una etapa posterior, mediante un método de optimización.

Interpretación

¿Cuándo utilizar ≥?

Se utiliza cuando el problema establece una cantidad mínima. Si la empresa tuviera que producir al menos 20 camisetas, se añadiría:

x + y ≥ 20

Esta condición es un ejemplo adicional; no pertenece al planteamiento original de la empresa.

Expresiones como «al menos», «como mínimo», «por lo menos» y «no menos de» suelen indicar una restricción de este tipo.

Cierre

Conclusión

Formular un modelo permite transformar una situación real en una representación matemática. Primero se identifican las decisiones, los datos, el objetivo y las restricciones. Con esos elementos se construye un modelo que posteriormente puede resolverse mediante un método adecuado.
